# SQL Memory：互動與視覺

本頁只定義 History／Favorites／Usage 特有的互動；共用骨架、清單列與篩選行為分別見
[視窗骨架](ui-windows.md)、[清單列](ui-rows.md)及[篩選](ui-filters.md)。

工具選單與工具列的 **History**、**Favorites** 聚焦同一個 **SQL Memory** Tool Window；
殼層保存停駐位置，不另建預覽視窗或位置設定。

## 主從瀏覽

- History 與 Favorites 共用 Browser、`SqlMemoryList`、卡片、搜尋、連線篩選與選取流程；
  分頁只決定查詢與可用操作。收合預覽保留選取，展開時才讀取目前項目。
- 單擊或 ↑／↓ 只選取並預覽；選取去彈跳後非同步讀全文，立即清除舊 SQL。
  取消、選取識別與宿主世代阻擋過期回應；收合、隱藏、停用與 Dispose 都取消讀取。
- 雙擊或卡片本身的 Enter 才開新 Query；操作按鈕的 Enter 只執行該動作。
  Delete 發出刪除請求；右鍵先選取該列。選取永不開窗或執行 SQL。
- 每頁 50 筆，捲到底可自動續頁，也保留手動按鈕。頁尾不參與選取，版面或資料增高不得觸發續頁。
  重整可恢復仍在第一頁的選取；沒有選取時預覽第一筆但不搶焦點。
- 卡片顯示名稱、狀態、連線、時間與單行 SQL；順序及窄版降級遵守[清單列](ui-rows.md)。
  合併執行以中性「×N」標記；完整 SQL 只在 Detail 顯示。
- 卡片、快捷選單與 Preview 共用同一組命令，順序是開新 Query、複製、加入收藏或編輯收藏、
  版本歷史，最後才是刪除。不適用的命令收起；Preview 的主要動作是開新 Query，
  全文複製與顯示換行留在左側工具列。

Preview 使用共用 SQL viewer，支援著色、選取、Ctrl+C、全文複製與只影響顯示的換行。
載入、空 SQL、內容已回收、停用與失敗都要清除舊內容並顯示狀態。
資料庫版本不相容或損毀時，整個主從區改顯示復原卡片；使用者確認後封存舊庫並重建，
也可開啟資料庫目錄。重建進度與結果走[通知卡片](notifications.md)，狀態列只顯示備份檔名。

第一頁與 Preview 用共用狀態表面；續頁進度留在頁尾，不遮住已載入列。
列進退場以資料旗標觸發，容器重用不重播。Preview 摘要依序顯示檔名、狀態、次數、伺服器、
資料庫、時間；合併列顯示首次與最後執行，收藏只標示「收藏」，不推測來源狀態或時間。

## 篩選與工具列

History 預設全部種類、七天、所有連線；狀態、期間、連線是同一列的三群。
Favorites 只保留伺服器與資料庫篩選。搜尋獨佔第一列，Ctrl+F 聚焦；右緣是
**目前連線**與**重新整理**，沒有排序。

伺服器與資料庫都是多選；未選代表全部。只載入部分名稱時，「全選」只能選已載入項目，
必須明示仍有下一頁。動到伺服器即清空資料庫選取；**目前連線**取代而非追加 Server／Database，
只改篩選、不切換 SSMS 連線，無連線時保留原篩選並提示。

按鈕摘要只顯示單一名稱或數量，完整名單留在 Tooltip 與面板。名稱在開啟面板時才載入；
排序或續頁不得丟失已選項目，讀取失敗留在面板內。共用控制項與預設列的語意見[篩選](ui-filters.md)。

掃描預算提早結束時，頁尾顯示搜尋截至日期並提供「繼續搜尋」；本頁沒有命中也不能誤報沒有資料。
篩選或搜尋改變時清除續搜進度，完整語意見[搜尋](sql-memory-search.md)。

分頁列只放 History、Favorites、Usage 與跨分頁的**設定**。Usage 以
[用量頁](sql-memory-usage.md)取代主從區，自己的狀態卡片負責重新整理。

## 收藏與開啟

History 項目可加入收藏：有版本時引用不可變版本，尚未產生版本的 Recovery 項目才以目前全文建立。
查詢視窗快捷選單與工具選單也能加入收藏；有選取收選取，否則收整份查詢。此入口不寫 History，
不受擷取設定影響；SQL Memory 未啟用或編輯器空白時停用。

收藏可編輯或移除，History 可刪除；刪除與移除都要確認且取消為預設，移除收藏不刪 History。
成功後保留既有分頁並選取原位置下一筆；編輯後的收藏移到最上方，若不再符合篩選則移出。

複製、開新 Query、收藏與單筆刪除等結果已在眼前的動作，只回報在工具窗；維護、清除、壓縮、
備份、重建與回溯等長操作走[通知](notifications.md)。

新增與編輯共用 `FavoriteEditorWindow`，一次儲存名稱、連線標註、說明與 SQL；SQL 未改就引用原版本，
改動才建立新版本。未存變更時關閉需確認；提交中不得關閉，Conflict 或未知回應保留輸入且不重送。
版本歷史維持獨立對話框，見[版本歷史](sql-memory-revisions.md)。

開新 Query 永遠沿用目前 SSMS 連線，不採用歷史標註也不執行；只寫入新建且仍空白的編輯器，
失敗時仍可複製 SQL。本版不提供覆蓋目前 Query 或批次刪除。
自動 WPF 渲染與 SSMS 實機驗收範圍見[驗收](sql-memory-validation.md)。
