# 資料字典

本頁包含資料字典工具窗的檢視、過濾、說明編輯與寫回；伺服器與資料庫的範圍規則見
[範圍](search-scope.md)，工具列與主從區的版面見[視窗骨架](ui-windows.md)。

資料字典一次看一台伺服器上的**一個**資料庫：使用者資料表與檢視、它們的資料行，以及
`MS_Description` 這一個擴充屬性。只改說明，不改結構：會動到資料的變更要使用者自己在查詢視窗按執行，
不在這裡做。

## 兩種檢視，一份狀態

- **資料表**（主從）：左邊資料表，右邊選定那一張的資料行。資料表自己的說明在主清單上直接改。
- **資料行**（資料字典）：每一個資料行一列，照名稱排、不分大小寫，同名的排在一起，比的是型別與說明
  在各表是否一致。這一種要把全部資料行排一次，只在切過去時才排。

兩種檢視讀的是同一份過濾、同一份編輯、同一批列物件（`Ssms22/Dictionary/SqlDictionaryBrowserModel`）：
在一種裡改過，切到另一種要看得到，而「有幾項變更」只能有一個答案。

## 過濾

一條規則（`Metadata/Dictionary/SqlDictionaryFilter`）同時決定主清單、明細與資料字典檢視留哪幾列：

- 字串比對資料表名稱（`schema.name`）與資料行名稱；空白或逗號分開的幾個字任一命中就算。
  大小寫與全字開關照 `TextMatcher`。是字面比對，不是模糊比對：要找的是「這個名稱出現在哪些表」，
  模糊比對會把不相干的名稱也拉進來。
- 物件名稱命中時整張列出；只命中資料行時只列那幾個。條件面板可以限定只比對其中一種。
- 「缺少說明」「同名卻不一致」「不含檢視」疊在字串之上。條件都沒勾就是不限。

## 同名資料行

同名的判斷不分大小寫（`SqlColumnNameGroups`），否則 `ReaderNo` 與 `READERNO` 會各自成群，
正是要比的那一組被拆開。一群裡型別或說明有兩種以上就是不一致，同名那一格換警示色、
停留時列出每一種寫法，最常見的在前面。

一群裡寫過的說明**只有一種**、而有幾格空著時，空著的那幾格淡色列出那一句，右鍵「照抄同名的說明」
一次補上。寫法不只一種時不給建議：哪一句是對的要人判斷，替他挑一句等於把錯的那一句複製到更多表上。

## 編輯

- F2 或在選定的那一格上再點一下就能改；Delete 清掉選定那幾列的說明（套用後是卸除那個擴充屬性）。改回原值就不算變更。
- **Ctrl＋V 貼上試算表**（`SqlDescriptionPaste`）：一欄時從目前那一列往下一格一列；兩欄時第一欄是名稱，
  可寫 `資料行`、`資料表.資料行` 或 `結構描述.資料表.資料行`，同名的每一列都補，對不到的那一行
  （通常是標頭）算略過。「複製名稱」給的是完整名稱，貼到試算表寫好說明後可以整份貼回來。
- 編輯照「伺服器＋資料庫」各記一份。換資料庫因此不必先問要不要放棄：那一問得擋在範圍列上，而範圍列
  是共用的，不該知道哪個視窗有未存的東西。關掉工具窗才丟；換介面語言時模型交給重建的那一份。
- 超過 3750 個字元（`SqlDescriptionValue.MaxLength`，`sql_variant` 的 nvarchar 上限）時套用停用。

## 寫回

套用只有一條路：打開預覽 → 看整份指令碼 → 執行。變更在打開預覽時就定下來，預覽的就是要執行的那一份。

- 指令碼（`SqlDescriptionScript`）先 `USE`，`SET XACT_ABORT ON`，整份包在一個交易裡；每一項依新值與
  原值決定新增、更新或卸除，物件本身排在它的資料行之前，同一批變更每次產生同一份文字。
- 執行（`SqlDescriptionWriter`）在同一個交易、同一條連線上先讀伺服器上現在的值：跟原值與新值都不一樣
  的就是別人改過，整批退回、一項都不寫。被擋下之後換上伺服器現在的值當原值並重新載入，
  使用者看過之後再按一次就是覆蓋；不自動重試，否則等於替他決定了誰的版本留下。
- 「在查詢視窗開啟」把同一份交給使用者自己執行。字典那一台與查詢視窗不是同一台時開未連線的視窗，
  否則按 F5 會在另一台上執行。
- **收尾一律是重新載入**（`SqlDescriptionEdits.Settle`）：伺服器上已經是編輯那一句的不再算變更。
  自己寫回的、在查詢視窗執行過的、別人剛好寫了同一句的都走這一條；寫回之後另記哪幾項成功的話，
  查詢視窗那一條永遠收不到，畫面會一直掛著已經生效的變更。寫回成功後只作廢改到的那幾個物件的
  中繼資料快取，補全與預覽才看得到新說明。

通知都歸 `Dictionary` 種類，開關見[可見度](notifications-visibility.md)。
