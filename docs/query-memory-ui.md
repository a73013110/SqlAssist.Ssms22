# SQL Memory UI

SqlAssist toolbar 與工具選單提供含主題圖示的 **SQL History**／**SQL Favorites**。
兩個命令聚焦同一個 **SQL Memory** Tool Window，分別選取歷史／收藏頁；不新增全域快捷鍵。
Favorites 對應既有 `SavedQuery`／Saved Queries；不更名設定 moniker、儲存格式或既有命令 ID。
殼層保存停駐位置，獨立預覽的位置另存於 VS 使用者設定存放區。

## 瀏覽與預覽

- 歷史預設全部類型、最近七天、所有連線；可切換執行／草稿、期間及精確伺服器／資料庫。
- 收藏預設全域；伺服器／資料庫分開切換，不合併父層，不按 Pinned 跨頁重排。
- 搜尋區分大小寫、不吃萬用字元；歷史搜尋 SQL，收藏搜尋名稱、說明與 SQL。
- 搜尋獨佔一列，放大鏡與清除鈕內嵌；Ctrl+F 聚焦。類型與期間以同列膠囊選取，窄窗才換行。
- 頂列分頁靠左、操作靠右，統一垂直中心線；重新整理／設定使用向量圖示，窄窗收起文字但保留 Tooltip。
- 伺服器／資料庫各一列，可點標題收合但保留條件；可依最近使用、最早使用、名稱升／降冪排序。
  名稱由儲存層獨立分組查詢，不受前 50 筆清單限制、不讀 SQL；每次取 100 個及一個續頁訊號。
  「更多名稱」以 offset 續讀；同步寫入時可能移動位置，重新整理可重取，不影響歷史的 keyset 分頁。
  資料庫名稱隨伺服器收斂，歷史名稱不受搜尋／期間限制；收藏名稱限定所選 scope。
- 「目前連線」向 SSMS 讀取 `ActiveSqlEditor` 對應 moniker 的最新連線，一次套用 Server／Database。
  無可用連線時保留原篩選並提示；收藏切到 Database scope，不合併其他 scope。
- 卡片使用 5 DIP 圓角淡邊框、5% 主題懸停色、Accent 選取框；移除虛線焦點但保留實線鍵盤焦點。
  執行沿用 Accent、草稿沿用中性 badge；狀態不僅靠顏色。連線 badge 預設中性主題，樣式集中於 Chrome。
  SQL 使用等寬雙行代碼區塊；時間顯示相對時間與時分，每分鐘更新，Tooltip 保留精確日期秒數。
- 列內提供複製全文、開新查詢、加入收藏、預覽；懸停或鍵盤進入卡片時顯示，也保留右鍵操作。
  不再顯示底部預覽／開新查詢按鈕；Enter 在卡片開預覽，在快捷按鈕則執行該按鈕。
- 每頁 50 筆，以 opaque cursor 續頁；同一輪分頁固定時間界線，不重新計算「最近七天」。
  畫面只顯示已載入筆數；換條件取消舊請求並更新世代，晚到結果不能改新清單。
- 列表只取 240 字元預覽。SQL 全文僅於預覽、複製或開新查詢時按需讀取。
- 單擊只選取，雙擊／Enter／預覽按鈕開啟獨立非模態預覽；開啟後跟隨選取，等待 220 ms
  才讀全文，不反覆聚焦。手動關閉後單擊不會重開；工具窗隱藏時關閉預覽並取消讀取。
- 預覽沿用 `SqlScriptDocument` 著色及 `SqlScriptTheme` 動態資源，沒有編輯器時使用主題備援。
  不沿用 IntelliSense 空間保留或 popup 生命週期；全文與選取複製映射回原文，換行切換只改顯示。

## 收藏與開新查詢

已有 Revision 的歷史可以加入收藏。Recovery 沒有 RevisionId，首版只能預覽或開新查詢，
加入收藏按鈕停用並解釋限制，不建立假 Session。

收藏 metadata 與 SQL 使用兩個編輯對話框，分別呼叫既有 CRUD 與 SQL 編輯交易。
SQL 編輯是可重用純文字控制項，提供原文／修改狀態／唯讀能力，不含 IntelliSense。
取消未存 SQL 會確認捨棄；儲存期間不允許關閉。衝突保留輸入，要求複製後重新整理；
回應不明也不盲目重送非冪等編輯。刪除須確認，不連帶刪除歷史。

「開啟至新查詢」沿用目前 SSMS 連線，不依歷史或收藏 scope 切換連線、不執行 SQL。
仍走 `SsmsScriptWindow` 與 `TextViewEditCoordinator`，只寫入剛建立且仍空白的編輯器。
沒有可沿用連線時顯示失敗，SQL 仍可複製。

## 生命週期與共用邊界

UI 透過宿主受保護的背景操作存取隔離儲存，不持有 repository。UI 操作、手動整理、
維護與卸載共用閘門；先等待已派送呼叫與 writer 排空，才在背景卸載 AppDomain。
儲存重新開啟會更新世代，舊請求不能在新宿主繼續操作或呈現結果。

停用時不開儲存、不讀取既有資料，只顯示設定入口。工具窗定期讀取記憶體狀態，
顯示啟用失敗、寫入器停止或佇列拒絕；不因此自動重新讀取或重排歷史清單。

字型與樣板遵循[UI 準則](ui-guidelines.md)。共用 SQL viewer／文字 editor 留在 UI，
收藏、版本與儲存流程留在 QueryMemory；不建立另一套視窗框架。

## 驗證與安裝

本次未安裝到 SSMS，不把舊批次的實機 PASS 當成本版結果。

自動測試涵蓋分頁世代、遲到結果、失敗重試、精確原文與選取複製、編輯修改狀態；
另涵蓋名稱排序、範圍、100 個名稱續頁與隔離 DTO、相對時間邊界、膠囊收合及 Recovery 快捷操作。
WPF 元件渲染涵蓋明暗／彩色／高對比、320／440／740 DIP 與 100%／150%／200% DPI、虛擬化清單。
元件 PNG 在 `artifacts/theme-qa/`，不是 SSMS 宿主截圖。
命令表另跑 `tools/Test-CommandTableToolbar.ps1`，涵蓋 toolbar 根節點與一般選單錯誤結構。

命令資源版號 24；工具列名稱、圖示與收藏命令必須建置後 **Install**，不能只 Deploy。
實機仍須驗證：toolbar 與停駐、雙窗焦點、不同 DPI 螢幕間移動、無連線開新查詢、
設定停用／重啟、跨程序收藏衝突，以及既有物件預覽與 F12 共存。
擷取實測仍獨立依[實機驗收](query-memory-validation.md)記錄。

本版不含舊版本清單／還原、直接執行、覆蓋目前查詢、跨 scope 合併、批次刪除或任意 SQL 新增收藏。
