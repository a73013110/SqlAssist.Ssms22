# 浮動預覽外觀與進出場

本頁包含浮動預覽的外殼、陰影邊、長出與收起的動畫與載入膠囊；殼層與擺放見[浮動預覽視窗](preview-window.md)，
共用外觀見[自製 UI 準則](ui-guidelines.md)。

外殼（`PreviewSurface`）與內容（`SqlStructurePanel`）分開：內容與工具窗共用，圓角、柔影、
握把、抬頭的三顆工具與進出場只屬於浮動預覽。與通知島同一種浮層（`SqlAssistChrome.Surfaces`）：圓角 `FloatingSurfaceRadius`、柔影只掛在
底色層並點陣快取，高對比不畫影子。底色維持不透明，不用通知島的玻璃——一百多列的資料格
疊在透出來的 SQL 上讀不清楚。

Popup 以外畫不出東西，所以外圈留一圈透明的陰影邊（`ShadowMargin`），影子在自己的矩形
裡長。reservation 與可點擊區仍是整個矩形；這一圈同時就是與錨點、建議清單的間距，定位的
`LayoutGap` 因此是 0，否則是兩份間距。

進出場與通知島同一套語言（`UI/SurfaceMotion`、`UI/SurfaceCapsule`）：錨點下方的圓點先長成
膠囊，再攤開——寬先、高隨後落下，圓角從全圓收成表面圓角——內容晚 60 ms 才淡入並從 0.96
放大。表面依最終尺寸排好版，外形只由裁切露出，資料格不重排；讓內容跟著裁切一路露出的話，
外形還在長的時候整片資料格像從門縫裡擠出來。

**內容還沒到就停在膠囊。**膠囊寫著名稱、轉著與通知島同一顆進度圈，停多久由
`Core/Preview/PreviewReveal` 決定：寬限內到齊的看不到等待（快取命中是常態，一律先停等於人為
變慢），進度圈浮現後至少留一段免得一閃而過，到上限還沒到就照樣攤開，交給抬頭的「載入中」。
第二層的欄位到了就算到齊。否則先攤開一片只有標題的表面，看起來像這個物件什麼都沒有。

換內容有三種動法：跟著清單選取換的不動，方向鍵連按時每一格都動只會拖慢眼睛；釘住的窗
原地換，新內容浮上來；換到另一個名稱旁邊時舊位置縮回寫著新名稱的膠囊，收完才換上內容、
在新位置長出來；直接跳位的話，眼睛追不上是同一扇窗換了地方還是又開了一扇。

收起時內容先淡出、外形縮回膠囊、整個表面同時淡掉；清單上路過關鍵字而暫時收起時直接收，
否則每按一次方向鍵都有一段動畫。縮回期間內容還掛在舊的承載視窗上，而內容只有一份，新
Agent 掛上之前必須先 `CompleteExit`。

## 尚未確認

- 圓角下的角落握把仍拖得到、陰影邊點下去不會被當成點到後方的編輯器（100%／150%／200% DPI）。
- 冷快取時膠囊等待再攤開的節奏；Ctrl+F12 連續換名稱時縮回再長出不卡、不閃舊內容。
- 長出動畫在大尺寸（整個編輯器寬、上千 DIP 高）與遠端桌面下不掉格。
